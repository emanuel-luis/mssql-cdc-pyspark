# CLAUDE.md

Guidance for Claude Code when working in this repository.

`mssql-cdc-pyspark` is a platform-agnostic **PySpark DataSource V2 streaming source
for SQL Server CDC**, plus a Delta sink and a **completeness signal**
(`finalized_until`) for downstream consumers. See `README.md` for the product,
`docs/ARCHITECTURE.md` for how it works, `docs/DESIGN.md` for why.

## Commands

Per-platform setup (Linux, Windows with WSL2, Windows native) is in
`docs/DEVELOPMENT.md`. Native Windows also needs `HADOOP_HOME` (winutils) and
`PYSPARK_PYTHON` pointing at the venv interpreter.

```bash
uv sync                                             # .venv + dev group (pytest, Spark, Delta, Faker, mssql-python)
. .venv/bin/activate                                # or prefix every command with `uv run`

pytest -q                                           # unit tests, no SQL Server needed
MSSQL_CDC_TEST_DELTA=0 pytest -q                    # skip trying to resolve Delta jars (faster)
pytest tests/test_source_fake.py::test_idle_dummy_entries_advance_offset_and_finalization

cp .env.example .env && docker compose up -d        # SQL Server 2022 + Agent
python -m lab.workload setup                        # db, tables, CDC
python -m lab.workload seed | stream | bulk | long-tx
python -m lab.checks.t5_engine                      # t1..t7, see LAB.md
python examples/local_pipeline.py
```

`make` targets mirror these on Linux; `scripts/lab.ps1` is the PowerShell
equivalent. No linter/formatter is configured yet.

## Invariants (do not break without an ADR)

1. **Offset contract.** `{"lsn": "0x" + 20 uppercase hex, "commit_ts": "<UTC ISO-8601, ms>"}`.
   It lives in users' checkpoints: renaming keys or changing formats breaks resumes.
   `lsn` is the last *processed* commit LSN.
2. **Batches are commit-history prefixes.** A batch reads the closed interval
   `[fn_cdc_increment_lsn(start), end]` with `end <= sys.fn_cdc_get_max_lsn()`, and ends
   on a commit boundary (`maxCommitsPerBatch` counts `cdc.lsn_time_mapping` rows).
3. **Never** call `fn_cdc_get_all_changes_*` with `from > to` (Msg 313). `partitions()`
   returns `[]` when `end <= start`.
4. **Retention guard.** If `increment(start) < fn_cdc_get_min_lsn(ci)`, raise
   `DataLossError` unless `failOnDataLoss=false`. Silent skipping is data loss.
5. **Executors are stateless.** `read()` opens and closes its own connection; the
   reader drops `_client` in `__getstate__`. Nothing live gets pickled.
6. **LSNs cross every boundary as hex strings.** Bound as `CONVERT(binary(10), ?, 1)`,
   returned as `CONVERT(varchar(22), <lsn>, 1)`. That is what keeps backends
   interchangeable; do not bind or decode binary in Python.
7. **Every Arrow batch is cast to the declared Spark schema** before it is yielded.
8. **Sink idempotency.** `app_id` is stable for a checkpoint's lifetime; a new
   checkpoint needs a new `app_id` (batch ids restart at 0).
9. **Finalization ordering.** Data committed first, `finalized_until` advanced after,
   monotonic (`GREATEST` semantics). Never store it in `TBLPROPERTIES`.
10. **Platform-agnostic core.** Nothing under `src/mssql_cdc` imports `dbutils`,
    `databricks.*` or other platform APIs. Platform glue belongs in `examples/` and docs.
11. **SQL injection.** Anything inlined into T-SQL (capture instance, columns, timezone,
    integers) goes through the validators in `client.py`.

## Testing strategy

* `tests/test_source_fake.py` runs the real streaming engine in local mode against
  `FakeCdcDatabase`: add a test there for any change to offsets, batching, guards or
  output schema. The fake must keep matching real CDC semantics (see `docs/DESIGN.md`);
  when a lab check reveals a difference, fix the fake too.
* `tests/test_client_sql.py` pins the T-SQL shape.
* `lab/checks` prove SQL Server behaviour; CI (`.github/workflows/ci.yml`) runs them
  against `mcr.microsoft.com/mssql/server:2022-latest`.
* Claims in docs or write-ups must be backed by a check result in `lab/results/`.

## Open questions to settle with the lab

  `tran_end_time` follows the server's local clock (t2).
* Delta: `userMetadata` via session conf on MERGE; MERGE idempotency via session txn
  confs (t6).

## Conventions

* English in code, docs, commit messages. Python ≥ 3.10, type hints, small modules.
* PySpark is an optional extra (`[spark]`): platforms ship their own. Do not add hard
  dependencies to `[project].dependencies` beyond `pyarrow`.
* Keep the README options table and output schema in sync with `source.py`.
* Record design changes as a new ADR in `docs/decisions/`.
